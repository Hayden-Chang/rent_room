# 用户编辑数据保护

本目录是用户持续编辑的看房脑图与 HTML 清单。数据与页面代码必须分开处理。

- 当前编辑稿：`recovered/current-tree.json`。不能把旧导出、默认数据或恢复种子当成最新版覆盖它。
- 改程序前，备份当前稿并记录校验值；有正在编辑的浏览器时，通过界面导出实际当前稿并等下载完成，再核对内容。若两份不同，保留两份并先定位未保存草稿。
- `build-recovered.mjs` 只能读取当前稿生成页面；不得重置已存在的当前稿。
- 用隔离数据目录测试保存、删除、导入、恢复、冲突和断线。禁止在用户主稿上写测试字段。
- 交付时核对实际编辑稿的内容、节点 ID、层级、顺序、类型和选项，不能仅凭条目数量宣称保留了修改。
- 脑图与 HTML 共用同一数据源。服务端执行版本检查、原子写入、保存前归档和第二目录备份。
- 历史版本不可覆盖或自动清理。恢复或解决冲突必须先预览差异，并保留磁盘旧稿及浏览器未同步草稿。
- 旧页面写入协议必须被拒绝，不能为了兼容绕过版本保护。
- 当前任务的实现和验收由当前 Codex agent 直接完成，不启用 worker 或派工。
