一、现场看房：硬件设施必查（逐条试）

1. 厨卫重点
- □ 马桶冲水力度足不足、会不会堵、会不会反味
- □ 公寓房专门问：马桶是粗管还是细管（细管易堵避雷）
- □ 洗手池、厨房水槽是否漏水、下水快慢、水槽深度够不够
- □ 全屋水压测试，洗澡水流大不大
- □ 厨房抽油烟机能否正常使用、冰箱制冷是否正常

2. 全屋家电 & 灯光电路
- □ 所有灯全部打开，检查是否有坏灯、暗灯
- □ 所有插座逐个试电，排查老化、没电、松动
- □ 空调试开关、制冷、有无异响
- □ 热水器能否正常出热水

3. 家具房屋细节
- □ 床架是否结实、床垫有无破损
- □ 床垫塑料膜能否拆（不能拆提前确认，避免扣款）
- □ 沙发底部、柜子、电视柜有无发霉
- □ 墙面脱皮、磕碰、划痕全部记录

4. 房屋居住三核心（你最重视）
- □ 隔音：关窗听隔壁、楼道、楼下噪音，不租 LOFT / 公寓（隔音差、商水商电贵）
- □ 采光：东南 / 南 / 西南，保证有日照时段
- □ 通风：开窗风能贯穿客厅入户，不闷不潮

5. 外部环境避雷
- □ 楼下是否商铺、美甲店、按摩店（容易吵）
- □ 附近有无小学、工地（白天长期噪音）
- □ 小区安保：门禁、保安、外卖能不能上楼
- □ 生活配套：快递驿站、超市、菜市场、公交地铁是否方便

# 租房攻略

**一、租房前要了解的事项⚠️**

1. 中介费：一般是半个月或一个月房租
2. 房租：押一付三较多，也有押一付一和签一年的
3. 物业费：一般是2块钱一平方
4. 水电费：民用水3～6/吨电0.5～0.8/度
   商用一般水4块/吨，电1.5/度
5. 燃气费：一般是2块左右/字

**二、租房前要问的问题🐱**

1. 房租是多少（押几付几，月付，季付）
2. 是不是民水民电（自己交还是房东代交）
3. 有没有物业费、网费（怎么收费的）
4. 有没有燃气能不能做饭（有些没有通气）
