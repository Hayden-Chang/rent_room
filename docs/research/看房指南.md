### 来源 02：奶酪馅白馒头 —— 租房 check list 可直接打印用（IMG_6293 ~ 6296）

#### 一、现场看房：硬件设施必查（逐条试）
1. **厨卫重点**：
   - [ ] 马桶冲水力度足不足、会不会堵、会不会反味
   - [ ] 公寓房专门问：马桶是粗管还是细管（细管易堵避雷）
   - [ ] 洗手池、厨房水槽是否漏水、下水快慢、水槽深度够不够
   - [ ] 全屋水压测试，洗澡水流大不大
   - [ ] 厨房抽油烟机能否正常使用、冰箱制冷是否正常
2. **全屋家电＆灯光电路**：
   - [ ] 所有灯全部打开，检查是否有坏灯、暗灯
   - [ ] 所有插座逐个试电，排查老化、没电、松动
   - [ ] 空调试开关、制冷、有无异响
   - [ ] 热水器能否正常出热水
3. **家具房屋细节**：
   - [ ] 床架是否结实、床垫有无破损
   - [ ] 床垫塑料膜能否拆（不能拆提前确认，避免扣款）
   - [ ] 沙发底部、柜子、电视柜有无发霉
   - [ ] 墙面脱皮、磕碰、划痕全部记录
4. **房屋居住三核心（你最重视）**：
   - [ ] 隔音：关窗听隔壁、楼道、楼下噪音，不租 LOFT / 公寓（隔音差、商水商电贵）
   - [ ] 采光：东南 / 南 / 西南，保证有日照时段
   - [ ] 通风：开窗风能贯穿客厅入户，不闷不潮
5. **外部环境避雷**：
   - [ ] 楼下是否商铺、美甲店、按摩店（容易吵）
   - [ ] 附近有无小学、工地（白天长期噪音）
   - [ ] 小区安保：门禁、保安、外卖能不能上楼
   - [ ] 生活配套：快递驿站、超市、菜市场、公交地铁是否方便

#### 二、现场必问问题（全部要问、全部要写合同）
1. **水电核心问题**：
   - [ ] 水电是民用水电还是商用水电
   - [ ] 电费单价多少、水费怎么算、是否均摊
   - [ ] 水表、电表位置在哪里
   - [ ] 水电是自己线上交、还是统一交给房东代缴
   - [ ] 索要物业联系方式
2. **网络问题**：
   - [ ] 现有有没有网
   - [ ] 能不能自己拉宽带
   - [ ] 可拉哪些运营商
3. **物业杂费**：
   - [ ] 物业费多少钱、谁承担
   - [ ] 物业费怎么交
   - [ ] 除房租物业外，有无任何隐形收费（保洁费、管理费、公摊费）
4. **付款方式**：
   - [ ] 押几付几
   - [ ] 月付 / 季付 / 年付具体规则
5. **房屋改造规则（非常关键）**：
   - [ ] 是否可以换锁
   - [ ] 是否可以贴墙纸
   - [ ] 是否可以打洞、粘挂钩
   - *(注：所有允许/禁止必须写合同，否则后期必赔钱)*
6. **维修赔付规则（你重点强调）**：
   - [ ] 家具家电、墙面、下水、灯泡、热水器、马桶自然老化、正常损坏：谁维修、谁出钱
   - [ ] 明确：租客人为损坏租客赔，设备老化房东全包
7. **退房押金规则（重中之重）**：
   - [ ] 退房流程是什么
   - [ ] 押金几天内到账（必须写具体天数）
   - [ ] 是否扣清洁费、电器损耗费
   - [ ] 水电结算有无官方单据、怎么核对账单

- **地漏**：矿泉水瓶装水快速倒下，是不是“咕咚”立马流干。
- **花洒**：开到最大，水压够不够；试试冷热水切换是否顺畅，水温调节反应快不快。
- **马桶**：连续冲 5 次厕纸，有没有回流或堵塞；掀开水箱盖，内部零件是否老化、有无水垢。

- **抽屉与家具**：各种抽屉和柜门打开关闭七八次看看，是否有松动；桌子、床和柜子等轻轻晃动，看看稳不稳；床垫材质是否为胶水床垫（甲醛含量多）；床架和床板，上去坐一坐、躺一躺，听听有无“吱呀”异响。
- **采光通风**：白天去看房，看阳光是否能照进来；把所有窗户打开，感受一下空气对流是否顺畅。

#### 四、生活细节检查
- **安全**：楼道有没有监控、灯光亮不亮，晚上回家楼道黑不黑；回家路会不会偏僻、小巷子多不多；周边治安好不好，有没有杂乱人员、夜宵摊吵闹扰民。
- **生活配套**：附近有没有超市、药店、菜市场；地铁公交远近，通勤时间多久，晚上下班有没有路灯。

#### 五、租房合同细节
- **核实身份**：核对房产证上的产权人姓名、身份证号与身份证是否一致；找房东直租提前问问是否可以给查看（如在直租小程序找房东，在介绍里说明可以查验房本）。
- **押金**：押金怎么退？退房后多久到账？会不会扣清洁费？
- **租金**：明确每月几号交租，通过什么方式支付，超时是否有滞纳金。
- **各项费用**：水电是民用还是商用？一度电多少钱？合租的话，水费是固定收还是 AA？有没有独立电表？没有的话怎么算？物业费、取暖费（北方）、网络费、垃圾清运费等由谁承担。
- **维修/改造**：家电坏了由谁负责维修？自然损耗是否由房东负责？墙面能否钉钉子、贴挂钩？
- **退租/转租**：提前退租怎么处理？能不能转租？转租有手续费吗？
- **养宠**：是否能养猫？或其他宠物？
- **备用钥匙**：是否有备用钥匙？可以换锁吗？
- **卫生**：退房前是否需要请家政打扫？如果需要，可要求房东在入住前请家政打扫一遍。

#### 一、租房前要了解的事项！
1. **中介费**：一般是半个月或一个月房租
2. **房租**：押一付三较多，也有押一付一和签一年的
3. **物业费**：一般是 2 块钱一平方
4. **水电费**：民用水 3～6 元/吨，电 0.5～0.8 元/度；商用一般水 4 块/吨，电 1.5 元/度
5. **燃气费**：一般是 2 块左右/字（立方米）

#### 二、租房前要问的问题！
1. 房租是多少（押几付几，月付，季付）
2. 是不是民水民电（自己交还是房东代交）
3. 有没有物业费、网费（怎么收费的）
4. 有没有燃气能不能做饭（有些没有通气）
5. 多久起租（有些房东要半年、一年起租）
6. 问清楚和谁签合同（中介，一房东，二房东，租户转租）
7. 一定要问中途能不能转租？转租流程怎样
8. 东西坏了谁去修？（日常损耗谁负责）
9. 在不改变装修格局的情况下，租户能否自行改造房间？
10. 能不能养宠物
11. 能不能帮忙办理居住证（外地人考试需要用上）

#### 三、看房注意事项！
1. 尽量白天有阳光的时候去看房，能更好看出采光如何，晚上看房一看周围噪音大小，二看房屋隔音效果
2. 尽量不要一楼和顶楼（一楼光线不好，吵，潮湿；顶楼夏天太热）
3. 小区周边环境（方不方便吃饭，买东西，出行）
4. 看墙面有没有发黄发霉、掉墙皮，地板有没有漏水、回潮（新装修的房子注意甲醛问题）
5. 看配置的家具家电损耗程度，没有的家具家电问房东能不能配
6. 检查有没有损坏的，坏的能不能让房东换（入住前把每个家具家电不管好坏都录个视频，避免后续退租房东扯皮）
7. 门锁安全（尽量自己换个锁）

#### 四、签合同注意事项！
1. 合同内是否清楚水电费以及网费燃气费？水电气多少钱，网费怎么收？是否包括在房租里？
2. 违约：租期内房东违约收房、涨房租赔偿多少钱？（自己转租是否需要手续费，需要提前多久说）
3. 明确入住后维修由谁负责。注：合同注明“乙方在租房期间，甲方不得再收取以任何名义为由的附加费用”
4. 要求房东出示房产证、身份证（有时签合同不一定能见到房东，但正规中介会给看房东房产证和身份证复印件、电话）
5. 明确房租（月付/季付/半年付），租房日期（一般会有几天的搬家过渡期，要自己说），租房期限，交租日期
6. 拍水电气表，看上个租户剩了多少（要么写进合同里，要么结算清）

- 先跟房东/中介问清楚这些：
  - 水电费怎么交？自己交还是房东代交？民用还是商用？
  - 东西坏了谁修？门、柜、洗衣机、空调、灯、厕所、下水道堵了怎么办？响应时间是多久？
  - 网络：有没有？费用谁出？
  - 物业费：谁交？还有其他零碎费用吗？
  - 墙面：可以贴贴纸、挂钩、钉子吗？
  - 换锁芯：可以换吗？房东是否保留钥匙？
  - 房租：押几付几？每月几号交？月付还是季付？
  - 退房条件：如果住了一段时间发现吵闹、潮湿等问题想退房，有什么手续？
  - 退押金：会不会扣消毒费、卫生费、门卡门锁使用费、电器损耗费、电梯使用费？要在合同上写清楚
  - 退房卫生：退房时要不要请家政打扫？如果要，入住前也帮我打扫干净
  - 是否会涨价：续租时会不会涨价？涨多少？

#### 4/5 签合同前必须确认的问题（身份核查与合同条款）
- ⚠️ **确认对方身份**：
  - 房东本人出租：看房产证＋身份证（两证名字要对上）
  - 二房东转租：看原租赁合同＋房东同意转租证明
  - 中介代租：看委托书＋公司营业执照
- ⚠️ **合同条款**：
  - 租期和交租时间：写的是几个月？每月几号交？
  - 租金＋押金：金额对不对？退押金条件是什么？多久退？
  - 费用明细：水电气多少钱一吨/度/方？民用还是商用？
  - 维修责任：东西坏了谁修？日常损耗（灯泡等）谁负责？
  - 违约条款：
    - 房东违约（提前收回房子）：赔偿多少？
    - 租客违约（提前退房）：赔偿多少？
  - 空白处：所有口头承诺都要写进合同！
  - 👉 **铁律：合同外任何转账都不要付！全部走合同！**

#### 5/5 入住前必做、安全第一与维权指南
- **入住前必做**：
  - 拍照录像：房间每个角落、家具家电、水电表读数
  - 把所有破损地方拍照发给房东，避免退房时扯皮
  - 测试所有电器：空调、热水器、洗衣机、冰箱、灯泡
  - 问清楚：如果入住一个月内坏了，算谁的？
  - 换锁芯（安全第一）
  - 检查摄像头（尤其卧室、卫生间）
  - 确认钥匙数量：门禁卡、钥匙几把
  - 结算清上个租户的水电费，不要帮别人交钱
- **安全第一**：
  - 小区监控、门禁、路灯齐全
  - 女孩子尽量别租太偏的地方
  - 逃生通道没有被堵
  - 独居的话，考虑买个门阻器
- **遇到问题怎么办？**
  - **Q：押金不退**  
    A：先沟通 → 报警 → 起诉
  - **Q：房屋有安全隐患**  
    A：立刻搬离 ＋ 要求退押金
  - **Q：中介威胁/诈骗**  
    A：保留证据 ＋ 报警 ＋ 12315 投诉
  - **Q：合同纠纷**  
    A：保留合同、转账记录、聊天记录

### 来源 11：孜然羊肉 —— 晚上看房提醒与居住细节避雷（IMG_6330 ~ 6335）
*对应图片：`IMG_6330.PNG` (2/7), `IMG_6331.PNG` (3/7), `IMG_6332.PNG` (4/7), `IMG_6333.PNG` (5/7), `IMG_6334.PNG` (6/7), `IMG_6335.PNG` (7/7)*

#### 2/7 重要提醒 & 采光通风
- 💡 **重要提醒**：尽量安排晚上看房！灯光、夜间噪音、真实采光遮挡，只有晚上才能真实体验到。
- 🔦 **采光通风 & 灯光（优先核查）**：
  1. **采光与楼栋遮挡**：观察楼前是否有高楼/建筑物遮挡，分清太阳照射方向，确认屋内能否接收到阳光直射，判断白天室内明亮程度。
  2. **通风效果**：每个房间开窗感受空气流通；尤其 LOFT 夹层，夹层普遍通风差，重点检查卧室、卫生间。

#### 3/7 灯具亮度 & 楼栋户型避雷
- 3. **灯具亮度（必须晚上看）**：打开全部灯具，看亮度是否够用；留意灯光会不会刺眼晃眼，房屋灯光昏暗，后期自己添置灯具会增加额外成本。
- 🏢 **楼栋与户型避雷**：
  1. **户型避雷**：不要对 LOFT 抱有幻想，普遍通风差，实际可用面积缩水，上下楼梯耗费体力，长期居住体验大打折扣。
  2. **梯户比**：优先选一梯两户，早晚上下班高峰电梯不会过度拥挤。
  3. **电梯实测**：观察开门速度、运行体感。电梯不完全看品牌，维保状态更关键。

#### 4/7 电梯维保 & 噪音与周边配套
- 电梯经验：二线国产电梯维保到位也很稳定，一线品牌维保差同样难用。
- 🔊 **噪音 & 周边配套**：
  1. **噪音（分白天＋夜间两次感受）**：长时间停留感受屋内噪音；留意是否临近铁路道口，会有持续低频轰鸣声；晚上重点听楼下街边噪音、商铺夜宵吵闹声。
  2. **楼下生活配套**：查看楼下基础生活设施：有没有饭店、小吃店，日常吃饭采购是否方便。

#### 5/7 房屋预留生活点位（生活硬件 & 居住痕迹）
- 观察房屋预留生活点位，判断是否适合长期居住：
  1. **卫生间**：有无吹风机挂位、毛巾杆；
  2. **阳台**：是否配备长度够用的晾衣杆，晾晒是否便利；
  3. **入户位置**：自带鞋柜，或者有空间可以摆放鞋柜。

#### 6/7 家电水路现场实测 & 主观居住感受
- 💧 **家电、水路现场逐个实测**：
  1. **洗衣机**：优先滚筒，波轮耗电更高；现场开机运转，确认全部功能正常。
  2. **热水器**：开启热水，测试出热水快慢、水温是否稳定。
  3. **所有水龙头**：厨房、卫生间每一个水龙头全部打开，检查水压大小、冷热水切换，查看有无漏水情况。
- ❤️ **主观居住感受（最高原则）**：
  - 房子看着各项硬件条件尚可，但身处屋里感觉压抑、别扭、浑身不舒服，直接放弃，不要勉强租住。

#### 7/7 总结升华
- 家是每天都要待的地方，无论租期长短，如果房子无法给到温馨放松的感觉，长期住下来人的情绪和状态都会受负面影响。

- [ ] **纸巾**：测试马桶冲水力度、擦拭瓷砖缝与水管接口检查漏水及霉斑
- [ ] **卷尺**：测量床、衣柜、冰箱位、洗衣机位以及门框尺寸（确认自带家具能否搬进）
- [ ] **手电筒 / 手机闪光灯**：探照床底、柜子背板、水槽下橱柜、天花板暗角
- [ ] **指南针 APP**：实测门窗真实朝向（判断是否正南、有无严重西晒）
- [ ] **甲醛测量纸 / 检测剂**：尤其是新装修房，检测甲醛超标情况
- [ ] **原房源截图**：现场逐一核对实际房屋与线上照片、房型、配置描述是否一致

#### 2. 看房策略与预算谈判心理战
- [ ] **预算试探策略**：中介或房东问预算时，报出的预算比心理底线低 **300 ~ 500 元**，套出合理区间内的优质房源，保留砍价余地。
- [ ] **多平台比价**：同小区、同户型在不同平台对比，争取免租过渡期（3~7天）与网费/物业费打包赠送。
- [ ] **“串串房”特征排查（甲醛重灾区，坚决避坑）**：
  - 装修极新（网红风、Ins风、轻奢风），但全是用廉价拼合木板、胶水板；
  - 窗帘色彩异常艳丽，床垫塑料保护膜未拆封；
  - 家电看似全新，但全是杂牌、三无山寨品牌；
  - 进门有浓重香薰味或刺鼻化学品气味（用于掩盖劣质装修与胶水甲醛味）。
- [ ] **看房黄金时间节点**：
  - **白天（下午 2~4 点）去看采光**：看阳光能否直射进屋，看自然光照是否充足；
  - **晚上（晚 7~9 点）再去看一次**：看夜间噪音（马路、邻居脚步声、外卖夜宵摊）、看楼道灯光安保、看灯具实际照明效果。

### 阶段二：外部环境与小区安保实地排查

#### 1. 通勤与周边配套
- [ ] **通勤实测**：拒绝“直线距离”，使用导航步行或骑车实测到地铁站/公交站的耗时（建议步行 ≤ 1 公里，单程通勤 ≤ 40 分钟）。
- [ ] **餐饮与生活**：楼下是否有超市、便利店、菜市场、药店、饭店小吃，日常采购是否便利。
- [ ] **快递与外卖**：快递是送货上门、快递柜还是菜鸟驿站？距离多远、几点关门？外卖能否直接送上楼？
- [ ] **电动车使用环境**：电动车停在哪里？有无充电桩及车棚（下雨会不会积水受潮）？充电收费标准如何？
- [ ] **垃圾投放点**：垃圾站/垃圾房在哪里？是否靠近卧室窗户（夏天易恶臭招蝇虫）？是否强制定时分类？

#### 2. 小区治安与楼栋环境
- [ ] **小区门禁与保安**：是否有 24 小时保安？外来人员登记是否严格？小区内部是否有死角监控？
- [ ] **夜间归家安全**：晚上下班回家的小巷子、楼道路灯是否明亮？周边有无杂乱无序人员？周围最近的派出所距离？
- [ ] **单元楼道**：楼道照明是否完好？公共区域卫生如何？是否有堆积杂物或易燃物？逃生通道是否畅通？
- [ ] **电梯实测**：
  - 梯户比是否合理（优先一梯两户，避开早晚高峰严重拥挤）；
  - 电梯是否运转平稳、开门速度是否顺畅；
  - 查看电梯轿厢内的**维保年检标志**是否在有效期内（维保比品牌更重要）；
  - 7 楼以上无电梯老旧小区需慎重考虑。
- [ ] **噪音源排查**：
  - 楼下是否临街、是否有酒吧、烧烤夜宵摊、美甲店、按摩店；
  - 附近是否有工地施工、小学/幼儿园（白天广播吵）、广场舞、铁路道口（低频轰鸣）。

### 阶段三：室内硬装结构、采光通风与居住隐患

#### 1. 采光、通风与主观感受
- [ ] **窗户朝向**：优先东南、正南、西南，保证充足日照；注意前方有无高楼或茂密大树严重遮挡。
- [ ] **对流通风**：开窗后空气能否贯穿入户，室内是否闷热、潮湿；LOFT 夹层普遍通风极差，需重点体验。
- [ ] **户型避雷**：尽量不租一楼（潮湿、阴暗、蚊虫多、无隐私）和顶楼（冬冷夏热、易漏水）；警惕 LOFT（商用水电贵、隔音极差、楼梯费力、夹层压抑）。
- [ ] **主观气场感受（最高原则）**：在屋里静静停留 10 分钟，如果感到压抑、别扭、浑身不舒服，即便硬件再好也果断放弃！

#### 2. 隔音效果深度测试
- [ ] **关窗与开窗对比**：关紧门窗，在屋内静听 1 分钟，测试马路车流、工地噪音是否明显。
- [ ] **室内关门测试**：关闭卧室门窗，让人在门外说话或放音乐，测试门板隔音。
- [ ] **楼板隔音**：敲击墙面听是否为空心轻体隔断墙；留意楼上走路、拖拉椅子的脚步声。

#### 3. 墙面、地面与防漏水检查
- [ ] **天花板与墙角**：仔细查看天花板有无发黄水印、水渍痕迹；墙角、窗框周围有无发霉发黑或受潮脱皮。
- [ ] **特殊“补丁”警惕**：若整面墙中仅有一块区域异常白净或重新刷漆，大概率之前发生过严重渗水或霉变。
- [ ] **地板与踢脚线**：地板有无翘起、发泡、塌陷，地砖有无松动空鼓；扒开床底、沙发底检查踢脚线是否受潮发霉。
- [ ] **虫害鼠害痕迹**：检查橱柜阴暗角落、踢脚线缝隙、水槽下方、冰箱背后是否有蟑螂粪便、虫卵或鼠迹。

#### 4. 门窗与锁具安全
- [ ] **入户防盗门**：开关顺畅、门缝严密不漏风、门把手无松动、猫眼清晰无遮挡；内侧反锁功能必须完好。
- [ ] **门锁更换权限**：确认能否更换锁芯（建议独居者自行更换 C 级锁芯，原锁芯妥善保留退租时复原）。
- [ ] **室内门**：各房间门能否顺畅关闭上锁，有无变形、异响或自动弹开。
- [ ] **窗户与纱窗**：锁扣牢固、密封胶条无风化开裂、纱窗完整无破洞、推拉顺畅无卡阻。

### 阶段四：全屋家具家电功能逐一实测（重点老旧家电）

> 严防“表面光鲜，一用就坏，退租被坑”！所有家电按以下细则当场开机试运行：

#### 1. 空调（耗电大户 & 故障重灾区）
- [ ] **制冷制热实测**：开机试运行 10~15 分钟，测试出风降温速度与制热效果。
- [ ] **异味与风口**：凑近风口感受是否有明显酸腐霉味、尘土味。
- [ ] **噪音与外机**：听室内机运行与摆风有无咔咔异响；观察空调室外机是否被奇葩安装在封闭阳台内部。
- [ ] **遥控器检查**：所有按键是否反应灵敏、液晶屏显示正常、电池仓无漏液生锈。
- [ ] **查看能效铭牌**：认准国标“GB 2 开头”新国标一级/二级能效变频空调；三级以上老旧高耗电定频机开一晚电费昂贵，需提前知悉。

#### 2. 冰箱
- [ ] **制冷测试**：通电检查冷藏室与冷冻室制冷是否正常。
- [ ] **冷冻结霜**：手摸冷冻室内壁，**若结冰结霜厚度超过 1 厘米直接要求房东除霜或慎重**，极其耗电且制冷差。
- [ ] **密封胶条测试**：关门时夹一张 A4 纸，向外抽拉抽不出来说明密封完好；若轻松滑落则胶条老化严重漏冷耗电。
- [ ] **异味与清洁**：打开门闻有无腐烂陈年异味；听压缩机运转噪音是否过大。

#### 3. 洗衣机
- [ ] **试运行与排水**：倒入小半盆水开启洗涤与脱水程序，观察进水、排水是否顺畅。
- [ ] **震动与异响**：高速脱水时机身是否剧烈晃动、有无刺耳金属刮擦噪音。
- [ ] **胶圈与桶内卫生**：扒开滚筒门圈橡胶缝，检查是否有陈年黑霉与污垢；波轮机检查过滤网袋是否破损发霉。
- [ ] **机型能耗**：优先选择滚筒洗衣机，波轮洗衣机耗水量与耗电量普遍更高。

#### 4. 热水器
- [ ] **通电与漏电保护**：确认电源插头带有漏电保护按钮且指示灯正常，插头干燥、接地良好。
- [ ] **加热速度与水温稳定**：开启热水，测试升温速度；放水持续观察水温是否恒定，有无忽冷忽热。
- [ ] **老旧隐患与耗材**：询问电热水器使用年限，确认内胆镁棒是否需要更换，检查泄压阀有无滴漏。

#### 5. 厨房厨电与小家电
- [ ] **抽油烟机**：开启所有风力档位，测试吸力强弱、运转噪音大小；检查油杯、风轮油污是否厚重漏油；检查公共烟道止逆阀是否起效（防楼下做饭油烟倒灌）。
- [ ] **燃气灶 / 电磁炉**：燃气灶逐个灶眼点火测试，火焰必须为纯净稳定的淡蓝色（黄火/红火燃烧不充分且熏黑锅底）；检查燃气软管是否老化龟裂；若为电磁炉测试加热与按键面板。
- [ ] **微波炉 / 电水壶 / 饮水机（若配备）**：通电试热，听有无异常火花声与塑料异味，检查漏水与漏电。

#### 6. 电视与电路设施
- [ ] **电视机**：开机测试屏幕色彩、有无花屏横纹；调试音量、接口及遥控器各功能；询问机顶盒费用是否包含。
- [ ] **灯具照明**：打开全屋所有灯（客厅、卧室、厨卫、阳台），看有无坏灯、昏暗灯；观察开关瞬间灯光有无闪烁频闪。
- [ ] **插座试电**：用充电器逐个插入房间每个角落插座，排查老化、接触不良、松动及无电插座。
- [ ] **电箱与偷电排查**：找到室内强电箱，确认空气开关标识清晰；在关掉屋内所有用电器后，观察电表脉冲灯是否继续闪烁，排查漏电或被偷电。

#### 7. 家具状态排查
- [ ] **床与床垫**：
  - 床架稳固度：坐在床边并用力晃动，躺下翻身，听有无“吱呀吱呀”刺耳异响；
  - 检查床板排骨架有无断裂变形，床腿有无垫纸或晃动；
  - 床垫：中间有无塌陷变形，表面有无陈旧污渍、异味、霉斑；询问是否为劣质胶水床垫；
  - **床垫保护膜**：向房东确认能否撕掉塑料膜（不撕不透气伤身，擅自撕掉有的黑心房东退租扣全款）。
- [ ] **衣柜与抽屉**：
  - 柜门、抽屉反复推拉开合多次，检查导轨滑轮是否顺畅，铰链是否松动脱落；
  - 打开柜门深呼吸闻有无刺鼻甲醛味或潮霉味；深度与抽屉数量是否满足生活收纳。
- [ ] **沙发、桌椅与生活点位**：
  - 沙发海绵回弹是否良好、有无明显塌陷骨架凸起；
  - 餐桌、茶几、书桌用力推摇，确认桌腿不晃；
  - **预留点位**：卫生间有无吹风机插座与毛巾杆？阳台晾衣杆长度是否足够？玄关有无空间放鞋柜？

### 阶段五：厨卫水路管道与防水下水深度检查

#### 1. 水压与水质实测
- [ ] **多龙头并开测水压**：将卫生间洗手台龙头、花洒与厨房水槽龙头**同时开到最大**，观察水压衰减程度，模拟晚间用水高峰期出水量。
- [ ] **水质检查**：用透明杯接水观察水质是否清澈，有无铁锈浑浊、泥沙沉淀或刺鼻异味。
- [ ] **冬季防冻**：北方或无暖气湿冷地区，询问厨房和阳台水管冬天是否容易受冻结冰。

#### 2. 下水速度与防反味测试
- [ ] **蓄水快排测试**：洗手池、厨房水槽放水蓄满大半盆，然后迅速拔开塞子，观察水流是否成旋涡快速排走，听下方管道有无“咕噜咕噜”反水声，用鼻子闻有无下水道臭气翻涌。
- [ ] **地漏瞬时排水测试**：拿一瓶 500ml 矿泉水（或接一盆水）直接倒向地漏，水流必须立即排干不溢出积水；检查地漏是否带防臭芯。
- [ ] **柜底管道潮湿测试**：用手伸进洗手台下方和洗菜池下方橱柜底部，仔细摸水管接口、弯头、下水软管处是否潮湿挂水珠、有无陈旧滴水锈渍。

#### 3. 马桶系统全体验
- [ ] **排污冲水实测**：往马桶内扔入一团揉碎的卫生纸，连续冲水测试（甚至连续按冲 3~5 次），观察冲力是否强劲、回水有无返涌漫溢。
- [ ] **管道粗细确认**：公寓房特意向房东/管家核实马桶排污管道是“粗管”还是“细管”（细管极其容易堵塞，属严重雷点）。
- [ ] **水箱与底部密封**：揭开马桶水箱盖，查看内部注水阀、进水浮球是否老化，有无黄垢水锈；马桶底座玻璃胶密封圈周围有无渗水渍迹或恶臭气味。

#### 4. 淋浴区与防水防潮
- [ ] **花洒与软管**：花洒喷孔有无水垢堵塞歪喷，软管两端有无开裂漏水，冷热水调节转换阀是否丝滑灵敏。
- [ ] **干湿分离与积水**：淋浴区挡水条是否完好，地面坡度是否合理（洗完澡水是否会自动汇入地漏，还是会在角落长久积水）。
- [ ] **排气扇实测**：开启排风扇，用一张纸巾贴在排气口看能否被牢牢吸住，听运转噪音是否震耳欲聋。

| **6** | **退租、转租与违约金** | ① 租期中途因工作变动提前退租，违约金扣多少？押金退不退？<br>② 租期内中途是否允许转租？转租是否收取中介手续费？转租成功后押金是否无条件全额秒退？<br>③ 若房东提前违约收房或任意涨租，房东如何赔偿租客？（如双倍返还押金 + 赔偿搬家费）。 |
| **7** | **退房卫生与押金退还** | ① 退租时押金在多少个工作日内退还？（必须写明具体天数，如 24 小时或 3 个工作日内）<br>② 退房时是否扣除“深度清洁费 / 卫生费 / 设施折旧费”？<br>③ 如果房东要求退房家政保洁，能否要求房东在**入住前同样请专业家政深度保洁一次**？ |

### 阶段七：签合同必查条款、身份资质与费用避坑指南

#### 1. 签约主体资质核验（防诈骗与假房东）
- [ ] **房东直签**：
  - 查验《房屋所有权证 / 不动产权证》原件 + 房东身份证原件；
  - 严格核对房本上的产权人姓名、身份证号与持证人是否 100% 一致。
- [ ] **二房东转租**：
  - 查看二房东与一手原大房东签订的《房屋租赁合同》原件（看租赁剩余期限，转租期绝不能超过原合同剩余期限）；
  - 必须查看原房东亲笔签署或出具的《同意转租证明 / 授权书》；
  - 核验二房东本人身份证原件并留底复印件。
- [ ] **中介 / 物业托管代签**：
  - 查看房东与中介公司签署的《委托出租代理授权书》；
  - 查验中介公司的营业执照原件/复印件；
  - 尽量争取“租客 + 房东 + 中介”三方签约；若中介单方代签，必须在转账账户上核实是否为公司对公账户或房东本人账户。
- [ ] **个人证件防滥用安全技巧**：
  - 给房东或中介提供身份证复印件时，必须在正反面文字上用黑笔手写批注：**“仅供本次 ×× 房间租房签约使用，他用无效，再次复印无效”**。

#### 2. 合同核心条款逐条审查
- [ ] **房屋信息明确**：详细精确到“某市某区某路某弄某号楼某室某房间（朝向/面积）”，切忌模糊。
- [ ] **租金与押金数字大写**：租金与押金数字除阿拉伯数字外，必须书写汉字大写（**壹、贰、叁、肆、伍、陆、柒、捌、玖、拾、佰、仟、万**），防止被私自涂改添零。
- [ ] **费用承担与单价明确写入**：水费、电费、燃气费、物业费、宽带费单价与承担方明文列入合同，严防口头约定。
- [ ] **维修责任分界线**：合同必须明文注明：**“房屋结构本身及原有家具、家电因自然老化、正常损耗导致的故障由甲方（房东）负责免费维修或更换；乙方人为故意或重大过失损坏的由乙方负责。”**
- [ ] **免除附加费用兜底条款**：合同必须附上声明：**“在租赁期限内，甲方不得再收取以任何名义为由的附加费用（如看房费、管理费、折旧费、设备使用费等）。”**
- [ ] **退还押金时限与清算**：写明：**“租赁期满或合同解除后，甲乙双方核验设施无误、结清应缴水电杂费后，甲方须在搬离之日起 [ 1 / 3 ] 个工作日内将全部押金全额无息退还乙方。”**
- [ ] **双方对等违约金约定**：房东中途无故收房违约、与租客中途退房违约，违约赔偿标准必须完全对等（如均约定为 1 个月租金金额）。
- [ ] **补充协议的法律效力**：如中介使用的是不得涂改的标准格式合同，所有口头承诺与特殊约定全部写在《租赁补充协议》中，双方签字按手印，法律效力等同于主合同。
- [ ] **转账铁律**：**所有租金、押金、中介费严禁私下微信转给业务员私人微信！必须走合同约定的对公账户或房东本人实名银行卡，并索要正规发票或加盖公章的收据！**

### 阶段八：交房入住留证、防偷拍安全加固与维权电话

#### 1. 交房当天全屋证据固化（防退租被坑终极防线）
- [ ] **水电燃气原始表底拍照**：入住交接钥匙当天，中介/房东在场时，立即拍下水表、电表、燃气表的当前读数特写，双方在交接单上签字确认，要求房东结清上任租客遗留的所有欠费。
- [ ] **全屋 360° 视频留档**：在空房状态下，沿着玄关、客厅、卧室、厨卫、阳台缓慢录制一段超清无死角的全景长视频（同时清晰记录日期时间）。
- [ ] **所有瑕疵细节特写拍照**：
  - 墙面开裂、污渍、掉皮、小洞、铅笔画痕；
  - 踢脚线发霉脱胶、地板烫痕、划痕、起翘；
  - 门框破损、窗帘小污点、柜门轻微变形、玻璃划痕；
  - 原有家具磕碰脱漆、纱窗微孔。
- [ ] **形成证据链并发微信确认**：将上述照片和视频打包发在房东/中介微信群中，附带文字：**“此为入住当天房屋交接现状留存，上述破损均为入住前原有瑕疵，退租时承租人不承担任何修复与赔偿责任。”** 得到对方明确回复“好的/收到”截屏保存。
- [ ] **清点钥匙与门禁卡**：清点入户大门钥匙、单元门禁卡、卧室门钥匙、信箱钥匙数量，登记在交接清单上。

#### 2. 人身与隐私安全加固
- [ ] **全屋防偷拍排查（尤其出租公寓/合租房）**：
  - 关闭全屋所有灯光，拉上遮光窗帘使室内完全黑暗；
  - 打开手机摄像头或红外检测仪，慢速扫描正对床铺、淋浴区、马桶的敏感位置：**插座插孔内部、烟雾报警器外壳、路由器面板、电视机边框、壁挂空调风口缝隙、卫生间挂钩、纸巾盒**；
  - 观察是否有肉眼不可见的红点反光或针孔摄像头。
- [ ] **门锁加固与独居防卫**：
  - 征得同意后更换超 B 级或 C 级防盗锁芯；
  - 独居女生建议网购便携式**阻门器（顶门器）**或门磁报警器，就寝时顶在门后。

#### 3. 官方维权渠道与应对指南
- [ ] **税务开票与偷税漏税投诉**：**12366**（税务服务热线。房东/二房东若拒开发票、私收房租偷逃税款，可直接向税务部门举报）。
- [ ] **押金拖欠、虚假宣传、中介乱扣费**：**12315**（市场监督管理消费者投诉） / **12345**（政务服务便民热线）。
- [ ] **遇中介黑恶势力威胁、强行撬锁驱赶**：保留现场录像录音证据，直接拨打 **110 报警**（出警记录是后续起诉与维权的关键法律凭证）。
- [ ] **小额诉讼法律起诉**：通过微信小程序“人民法院在线服务”进行网上立案起诉，凭租房合同、转账凭证、聊天记录主张退还押金及赔偿违约金，流程简便且成本极低。
