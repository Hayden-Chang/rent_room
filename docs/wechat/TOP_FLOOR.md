# 顶楼与异常标记

日期：2026-10-22。Draft PR #45；当前功能代码提交 `2292883cae84968ef233bb3aa1a1f5d080646255`。

## 操作契约

- 字段 `f1_top` 显示“顶楼”，保留“是 / 否”选项及原字段编号。
- 未填写不自动异常；选“是”自动计入问题；选“否”不自动异常。
- 用户已确认沿用左滑展开操作按钮。点击当前高亮的问题按钮可以取消，答案仍为“是”，已记录数、备注及媒体保持。
- 手动取消写入 `issueFlag:false`，重开、保存和导入后继续生效。再次手动标记也继续有效。
- 只有实际改变楼层答案时才清除旧覆盖并重新判断。相同值写回、备注编辑和重开均不清除覆盖。

## 历史兼容

按保存的模板问句识别旧语义：“非顶楼”的“是 / 否”反转为“顶楼”的“否 / 是”；旧“是否顶楼”或“顶楼”保持原值。没有模板的第二版清单沿用旧“非顶楼”语义，更早的正向问句保持原值；组合“底楼或顶楼”不推断为确定答案。

转换保留原答为 `previousTopFloorAnswer`，保留备注、媒体、显式问题覆盖及其他字段。`topFloorRevision:1` 防止重开或反复导入造成重复反转。本机加载、恢复、直接导入和备份准备均应用同一转换；归档只读保护保持。

iOS 的 JavaScriptCore bundle 由同一源码生成。iOS 组件评审见 PR #46（目标为现有 iOS 开发线，尚未合入主线）。
