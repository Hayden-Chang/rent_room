# 数字键盘核查（2026-10-24）

手机反馈：楼层打开文字键盘，面积打开数字键盘。原因是 `fieldView` 为允许输入负号，单独将楼层声明为 `text`。用户明确不再考虑负楼层，本次仅将楼层声明为 `number`，沿用现有输入框；不增加地下室选项、不迁移或删除已有记录。

核查当前两套清单及全部 WXML 输入入口：

- 详细模式 29 个数字字段中，26 个直接填写，3 个使用原有轮盘。
- 精简模式 23 个数字字段中，20 个直接填写，3 个使用原有轮盘；基本信息与费用复用详细清单。
- 楼层使用整数数字键盘；面积、长度、分钟、网速、金额、费用及自定义费用保持带小数点的数字键盘。
- 地址、备注、缺少配置、逾期利息/违约金等需写说明的字段保持文字输入；日期与选择项沿用现有控件。
