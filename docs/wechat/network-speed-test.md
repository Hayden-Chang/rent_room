# 实测网速：Apple CDN 下载测速

## 行为与范围

- 实测网速输入框右侧增加「测试」按钮，保留 Mbps 单位和手动输入。
- Wi-Fi 下进入专用测速页面即开始；其他可用网络先提示移动流量并征得本次确认。离线不发送下载请求。
- 成功后经应用唯一 store 持久化，自动返回清单并回填数字。只修改网速值，保留备注、问题标记、媒体和其他字段。
- 取消、退出、转入后台、网络切换、超时或服务异常不会覆盖原值；保存失败回滚并允许重试保存。测量期间原值被修改、房源归档或删除时禁止覆盖。
- 仅测当前设备到测速节点的下载吞吐，不测通话质量、不推定签约宽带速率，也不输出上传或延迟结果。

## 服务与流量

使用 `https://mensura.cdn-apple.com/api/v1/gm/large`，不携带业务记录、登录凭据或 API Key；服务端会正常看到访问 IP 等网络请求信息。采用本项目独立实现，没有复制第三方 CLI 代码。

通过 `wx.request` 和 ArrayBuffer 请求连续 Range，每段 256 KiB–8 MiB，目标约 8 秒，总期限 15 秒，完成下载累计不超过 64 MiB。禁用客户端请求缓存，校验 Content-Range、Content-Length（如有）、最终 HTTP 206 和实际字节数。不符合 Range 时在响应头阶段中止，避免完整下载服务端 4 GiB 文件。取消会中止当前请求；不自动重试或转发到开发者服务器。

计速口径为有效完整分段总字节数 × 8 ÷ 本次测量总耗时，包含建连和请求间隔；保留两位小数。分段请求开销可能低估高带宽，结果应作为现场下载参考，不宣称能跑满签约带宽。不足两个分段或耗时不足 500 ms 时拒绝回填。

2026-10-13 前置实测：公开配置接口可访问；指定阿里 DNS 解析出的金山 CDN 节点，两次 8 MiB 分段均返回 206，短测为 58.18 / 33.37 Mbps。本机默认流量经过隧道；该前置实验绑定 en0 并指定真实解析 IP，不代表正式小程序或三网实测。生产代码只使用域名，不固定 IP。

## 上线配置与待验收

1. 在对应 AppID 的微信公众平台「开发管理 → 开发设置 → 服务器域名 → request 合法域名」配置 `https://mensura.cdn-apple.com`。本实现使用 wx.request，不依赖 web-view 或 downloadFile。后台是否接受该域名尚未验证；若拒绝，不能通过关闭域名检查或硬编码 IP 上线。
2. 生产构建继续保持 `urlCheck: true`。在 iOS 和 Android 真机、关闭调试绕过的条件下验证正常下载、取消/后台中止、网络切换、失败后原值保留、自动回填和重开持久化。
3. 国内电信、联通、移动的实际 DNS 调度、可用性与吞吐尚待验证。苹果服务没有在本次找到第三方产品的可用性/免费配额承诺；本功能按外部服务可能失败设计，保留手动填写。
4. 界面效果待实际截图和用户确认后合入；未上传体验版、提审或发布。
