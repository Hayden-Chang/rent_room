# 小搭只向后引导（2026-10-24）

用户确认的规则：A 未填完，B 完成后引导 C；C 完成后引导 D；D 部分填写后，用户回到 B 修改并写完，跳过已完成 C，引导 D。前面的 A 由用户主动返回。

## 实现

- `xiaoda-flow.js` 从当前类别在房源清单中的位置之后查找第一个未完成类别，不按最近活动或阶段优先级回头。
- 普通向后推荐在后面没有待填项时结束；全屋完成提示仍要求所有有效项完成。现场有前置遗漏时不宣称“现场记录好啦”。
- 只有完成当前房源保存顺序中最后一个有效现场大项、向后目标为费用与合同时，提供“看看其他房子 / 去填写”阶段选择，不按固定名称判断，不要求补齐前面的现场项。有遗漏时提示“接下来要记录费用和合同吗？也可以先看看其他房子。”。较早的现场项即使后面现场项都已完成，也只显示普通向后推荐。
- 完成当前费用与合同列表的最后一个有效大项时，显示结束引导。有前置遗漏则提示“这套房子先记到这里，再看看其他房子吧。”；整套确实完成才使用完成文案。左侧“先等等”收起提示，停留原填写位置并保留答案；右侧“返回房源列表”才退出当前房源。收起后重进不重播，重新实际填写后可再次触发。
- 实际结果修改后类别处于完成状态即可重新引导。提示带上本次完成来源，动画和输入取消校验使用本次来源，不误用首次完成历史的最后一项。
- 答案、备注、媒体、模板顺序、首次完成历史与关闭小搭的作用域保留。
