# 小搭首次完成与补填场景（2026-10-24）

用户一次确认下列 20 条；第 6、18 条后续明确为“完成过就不再触发引导”。规则是每个大项首次完成才触发，并从本次位置按该房源保存的清单顺序向后找当前未完成项。A/B/C 指大项，多个有效字段需全部处理；有效的“不涉及”“无”“无费用”计入处理。历史最远位置不影响首次补填。

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| 1 | A 部分填写，首次完成 B，C/D 空 | 引导 C，不回 A |
| 2 | 首次完成 B，C 完成、D 部分 | 跳过 C，继续 D |
| 3 | A 仅填写一半 | 无下一项提示 |
| 4 | 末尾已完成，回来首次补完 A/B | A→B→C |
| 5 | 等待或返回列表、重进后首次补完 A | 同样引导 B |
| 6 | 已完成 B 内连续修改多个答案 | 不重复触发 |
| 7 | 首次补完 C，后面全完成、前面 A 未完成 | 停止本次引导，不回 A、不宣称全屋完成 |
| 8 | 首次补完较早 A 后整套真正完成 | 整套完成提示，先等等/返回房源列表 |
| 9 | 首次完成最后现场项，费用还有未完成 | 看看其他房子/去填写；允许前面遗漏 |
| 10 | 最后现场项已完成，首次补完较早 A，后面 B 未完成 | 优先 B |
| 11 | 首次补完较早 C，后面现场都完成，费用未完成 | 普通费用推荐，不是最后现场项的二选一 |
| 12 | 首次完成最后现场项，费用与合同全部完成 | 先等等/返回房源列表；前有遗漏不说全屋完成 |
| 13 | 首次完成最后合同项，前有遗漏 | 中性结束提示，先等等/返回房源列表 |
| 14 | 合同末尾 H 完成，F/G 未完成；首次补完 F | 引导 G |
| 15 | 模板保存顺序改变最后项名称 | 使用该房源实际保存顺序，停用项不参与 |
| 16 | 点击先等等/再等等 | 收起当前提示，位置和答案保留；其他大项首次完成仍引导 |
| 17 | 重开、相同答案、只改备注/照片/问题标记 | 不产生新完成提示 |
| 18 | 已完成 B 清空、重开、重新补齐 | 完成历史仍在，不重复触发 |
| 19 | 提示期间自主填写其他项 | 旧提示取消，新项首次完成按新位置判断 |
| 20 | 保存失败或关闭小搭 | 失败保留输入、不按完成推进；恢复保存后继续；关闭期间不提示且不补播历史 |
