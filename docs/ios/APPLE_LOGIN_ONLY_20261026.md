# Apple 单一登录方式（2026-10-26）

用户明确要求“先只做苹果账号登录吧”。本记录覆盖此前手机/微信登录计划；不修改小程序，不迁移或删除既有账号数据。

## 当前行为

- 我的页、扩容引导及组件预览仅显示系统“通过 Apple 登录”按钮。移除微信占位入口、手机号表单及其客户端 API；旧 Keychain 会话仍兼容读取。
- 先请求服务端挑战，成功后启用 Apple 按钮；准备中显示进度，失败显示“Apple 登录服务暂不可用，请稍后重试”和重试按钮。
- 系统返回身份令牌后才请求服务端会话，校验 provider、账号格式、令牌、有效期和容量后认领游客记录。仅取得挑战不建立登录状态。取消、过期和账号切换检查继续保留。
- 退出保留原账号目录，切到独立游客空间。新游客按正常流程完成首次设置和教学；没有为测试跳过这些业务步骤。

03 在 `ec61962` 上通过 9 UT + 3 UI，退出用例遗漏新游客首次设置；04 仅重跑该方法，层级显示首次房源教学仍隐藏返回按钮。05 补齐真实设置、四步教学和关闭反馈后，同一方法通过。两次失败均为测试前提遗漏，产品代码自 `ec61962` 后完全未变，没有放宽目标断言或增加等待时间。
